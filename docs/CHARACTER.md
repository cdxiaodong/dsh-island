# 新鲸鱼娘角色开发指南（AI 生图 → 动画角色）

本指南说明如何为 dsh-island 制作一套**新造型的鲸鱼娘动画角色**。
流程：**AI 生图 → 切分 → 集成**（切分与集成由代码处理，你只需提供生图）。

## 一、生图规范（来自 whale-girl sprites-spec）

**每张图 = 3×3 网格**（行 = 状态、列 = 帧；静态姿势 1 帧占 1 格）：

- 背景：**纯绿色 `#00FF00`**（无渐变/纹理/杂色）——鲸鱼娘配色与绿色完全不相交，抠图零歧义
- 角色：全身取景、居中、占画面约 80%，**人物一律朝左**
- 风格：参考 `originals/鲸鱼娘.png`（像素风鲸鱼娘）锁风格
- 动感状态：每帧画动作过程（横排帧间等宽、互不重叠、无分割线）

**生图提示模板**（每状态一行）：

> 生成 1024×1024 贴纸插画：纯绿色(#00FF00)背景。角色是像素风《鲸鱼娘》，画风/配色/线条与参考一致，全身居中占 80%，一律朝左。**<状态画面描述>**。动感状态加："画面为 N 个动作帧横排（从左到右为动作过程）"。

## 二、15 状态画面描述

| 状态 | 帧数 | 画面描述 |
|---|---|---|
| `idle` | 3 | 正面待机：第1帧睁眼、第2帧闭眼（眨眼）、第3帧微睁，身体呼吸起伏 |
| `working` | 3 | 一手托腮思考：头微倾、眼神专注、头顶小灯泡，三帧轻微晃动 |
| `celebrate` | 3 | 双手高举欢呼：起跳—腾空—落下，周围小星星 |
| `error` | 2 | 惊吓：第1帧正常、第2帧瞪眼张嘴呆毛炸起，一个感叹号 |
| `disappointed` | 2 | 低头垂肩：第1帧正常、第2帧低头含泪叹气 |
| `joy` | 2 | 眯眼咧嘴大笑，身体微倾，小爱心，两帧轻微摆动 |
| `eat` | 3 | 双手捧食物啃咬：咬下—咀嚼—咽下，腮帮鼓起 |
| `play` | 3 | 抛接小球：抛出—腾空—接住，身体蹦跳 |
| `drag` | 1 | 被斜向拉扯：身体倾斜双手乱摆（拖拽态由 tilt 摇摆） |
| `walk` | 3 | 侧面行走：抬左腿—落脚—抬右腿，身体微起伏 |
| `sleep` | 2 | 蜷缩闭眼睡觉：身体随呼吸起伏两态，头顶 Zzz |
| `wake` | 2 | 伸懒腰：打哈欠→揉眼睛 |
| `welcome` | 2 | 举手挥手打招呼：两帧上下摆动，小星星 |
| `think` | 1 | 沉思陪伴：双手托腮望远处（会话思考中，单帧+浮动） |
| `wait` | 1 | 等待回应：身体前倾看观众（等待批准，单帧+摇摆） |

## 三、切分与集成（交给 dsh-island 代码）

1. **准备**：按上面模板生成 15 状态的网格图（可 15 张单状态图，或合并）
2. **切分**：用 `panel/resources/` 下的切分脚本处理成帧 PNG（绿背景抠图 → 裁切 → 底中对齐 → 帧归一化）
3. **投放**：帧放进 `panel/resources/whale2/frames/<state>/`（全身）+ `panel/resources/whale2b/frames/<state>/`（半身）
4. **皮肤**：如需配色变体，运行皮肤生成脚本

## 四、注意

- 15 状态**缺一不可**（whale-girl 门禁要求全状态）
- 帧序要正确（AI 可能乱序，需校正）
- 角色配色避免洋红/紫（与绿背景混淆）
- 版权：生图角色需自有权（参考图仅锁风格，不复制原图）
