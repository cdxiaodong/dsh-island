## 一、当前鲸鱼娘形象分析

**造型结构**（从上到下）：
- 头顶一根**呆毛/触角**（深蓝）

- **深蓝渐变头发/大鳍**（头顶两侧 + 脑后）
- 蓝色圆润**身体** + 米白**肚皮**
- 底部蓝色**鲸鱼尾巴**（末端微翘）

**配色**（精确色板）：

**风格要点**：像素颗粒、圆润无棱角、Q版（头身比约 1:1.5）、线条简洁、朝左统一。

## 三、生成方式建议

**方式 A（推荐，最稳）**：15 个状态**逐个生成**（每张图 = 该状态的帧横排）
- 优点：每状态独立可控，帧序/动作准确
- 提示：把上面模板复制 15 次，每次替换【状态】段落

**方式 B（省次数）**：3×3 网格图（行=状态、列=帧）
- 一行一个状态（idle 3帧 / working 3帧 / celebrate 3帧…）
- 一次生成 3-4 个状态，再拼

**推荐用方式 A**：单状态生成质量更高、帧序不会乱。
