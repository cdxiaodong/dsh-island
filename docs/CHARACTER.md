# 鲸鱼娘 · 图生图（换肤/出动作）一条龙 Prompt

> 目的：基于**原版鲸鱼娘**（半写实 Q 版，非像素风）生成新素材。
> 核心思路：**不要文字描述角色长相**（文字锁不住画风，会跑偏成像素团子），
> 一律**图生图**——把对应参考图喂给 AI，只让它改"姿势 / 表情 / 配色 / 背景"。

## 一、万能锁定句（每段 prompt 开头必带）

```
严格保持参考图中角色的画风、五官、发型、女仆装、身体比例、鲸鱼尾巴、配色和线条风格完全不变，
绝对不要重新设计角色、不要改变画风、不要变成像素风。只按下面要求修改指定部分。
```

> 这一句是图生图不跑偏的关键。无论哪个工具，先把这句放最前面。

| 皮肤 | `<皮肤要求>` |
|---|---|

## 五、不同工具的"图生图"操作要点

- **即梦 / 文心 / 通义万相（国产）**：上传参考图 → 选"图生图/参考图" → 粘贴上面 prompt → 把"参考强度/相似度"调到 0.7~0.85（越高越像原版）。
- **Midjourney**：`--iw 2`（提高图权重），把参考图 URL 放 prompt 最前，后缀 `--s 50`（低风格化，防跑偏）。
- **DALL·E / GPT 图像**：直接上传参考图 + 文字，强调"保持角色完全一致，仅改 XX"。
- **Stable Diffusion**：用 img2img，`Denoising strength` 出动作设 0.45~0.6（要变姿势），换肤设 0.3~0.4（只改颜色），配合 ControlNet 锁线稿最稳。

> 通用原则：**变姿势 → 强度中等（0.5 上下）；只改色/换肤 → 强度低（0.3 上下）；越怕跑偏，参考强度开越高。**

## 六、生成完交给我

把生成的 PNG（原图、绿幕、横排帧）发我，我负责：
1. 绿幕抠图 + 按帧切分（横排 N 帧 → 拆成 00.png/01.png/…）
2. 帧对齐归一化（内容占比、底中对齐、统一尺寸）
3. 生成半身套件（托盘用，头+上半身）
4. 4 套皮肤接入皮肤系统
5. 加载进面板/托盘动画（沿用现有 15 状态行为引擎）
